# HopKeys

Своя клавиатура для Android от Hop Hop Studio.

- Раскладки: русская, английская, символы, цифры. Ряд цифр сверху по желанию.
- Стили: iOS светлый и тёмный, Material You, Liquid Glass, Tinted, Неон, Минимализм, Бумага, Графит. Свой цвет, фото на фоне, размытие (Android 12+).
- Буфер обмена с большой историей: закрепление, удаление, очистка. Пароли не сохраняются.
- Без интернета: в приложении нет разрешения на сеть, набранный текст никуда не уходит.

Сборка: GitHub Actions, каждый push выкладывает релиз с HopKeys.apk.
Чтобы обновления ставились поверх, добавь секрет `KS_B64` (тот же ключ, что у Hangar Vault).
